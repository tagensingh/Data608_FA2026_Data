# DATA 608 Fall 2026 - Data

Datasets for CUNY SPS DATA 608 (Fall 2026) data stories. Each story's data is in its own folder.

## Story 2
- `story2/Data608_FA2026_S2_fred_macro_monthly.csv` - Monthly fed funds rate, unemployment, CPI-U, core CPI, core PCE (FRED)
- `story2/Data608_FA2026_S2_fred_nrou_quarterly.csv` - CBO natural rate of unemployment, quarterly (FRED)

## Story 3
- `story3/Data608_FA2026_S3_state_master_2024.csv` - IIHS Fatality Facts 2024 state overview (course dataset)
- `story3/Data608_FA2026_S3_ems_response_by_state_2023_2024.csv` - FARS 2023-24 EMS response summary (course dataset)

## Story 4
- `story4/Data608_FA2026_S4_nyc_airbnb_listings.csv` - Inside Airbnb NYC listings (course dataset)
- `story4/Data608_FA2026_S4_neighborhoods.geojson` - NYC neighborhood boundaries (course dataset)

## Story 5
- `story5/Data608_FA2026_S5_train.csv` - Ames, Iowa housing sales 2006-2010 (De Cock 2011; course dataset)
- `story5/Data608_FA2026_S5_data_description.txt` - data dictionary
